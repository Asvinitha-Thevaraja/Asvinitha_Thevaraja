01 / Intelligent Learning Management System

InterLearn

Featured project Group project Role: Full-Stack Developer

An AI-powered learning platform that personalises learning for every student.

The need

Every student learns differently, but lecturers can't give each one personal attention. Learning needs to adapt to each learner.

What it does

An AI tutor helps students, emotion detection notices when a learner is struggling, and recommendations suggest what to study next. Lecturers manage courses, upload materials, run quizzes and track progress.

My part

Developed the React Native lecturer dashboard, built RESTful CRUD APIs with Node.js and Express, designed the PostgreSQL schemas and relationships with Sequelize ORM, and implemented learning-material uploads.

05 / Productivity Web App

Task Manager

Individual project Role: Full-Stack Developer

A productivity app that helps people plan, organise and finish their tasks on time.

The need

Students and small teams lose track of tasks and deadlines when work is spread across notes and chats.

What it does

Users add tasks with a priority level and a due date, search them, filter by All, Active or Completed, sort by newest, see how many tasks are left, and clear finished tasks in one click.

My part

Built the task interface with HTML5, CSS3 and JavaScript, created REST APIs with Node.js to add, update and delete tasks, and stored the tasks in a PostgreSQL database.
